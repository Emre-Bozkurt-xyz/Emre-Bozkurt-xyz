### 🚀 Featured projects

**[Vault](https://ems-place.com)** &nbsp;·&nbsp; `Next.js` `React 19` `Yjs` `PostgreSQL` `Cloudflare R2`
A self-hosted, Obsidian-style Markdown workspace with real-time CRDT collaboration, role-based sharing, public publishing, and permission-gated asset storage — deployed through a Dockerized home-lab stack behind Caddy + GitHub Actions.

**Constantia** &nbsp;·&nbsp; `Godot 4` `Rust` `SpacetimeDB` `GDExtension`
A cross-language multiplayer foundation: a Rust/GDExtension adapter wiring SpacetimeDB reducers, tables, and event draining into Godot, plus codegen that maps DB bindings to engine-facing APIs and OAuth2-backed player presence across desktop and mobile.

**Custom 3D Rendering Engine** &nbsp;·&nbsp; `C++17/20` `OpenGL` `GLSL` `CMake`
An OpenGL renderer built from scratch — GLSL shader pipeline, mesh buffers, camera math, and command-submission architecture with resource caching, used as a sandbox for GPU and graphics-math work.

**Strongest Dungeon Crawler** &nbsp;·&nbsp; `Roblox Luau` `Networking` `ECS-style`
A server-authoritative multiplayer RPG with client prediction and reconciliation — keeps combat responsive under latency while the server stays the source of truth, with a modular ability/status-effect system built to scale.
